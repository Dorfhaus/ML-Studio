# ML Pure Player

FluidSynth 2.6.2, tag v2.6.2, https://github.com/FluidSynth/fluidsynth. Complete engine source, authors and LGPL-2.1-or-later licence retained under vendor/fluidsynth. Native CMake build uses the cpp11 OS layer, 128 preallocated voices, one synthesis core and no device drivers/network/shell. No separate FluidSynth runtime is required. SF3/DLS decoders and Signalsmith extensions are disabled in this version; SF2 is supported. GCEM 012ae73c6d0a2cb09ffe86475f5c6fba3926e200 headers are vendored unmodified (Apache-2.0). All engine code builds from included source; build caches belong in the platform's existing registered location.

GeneralUser GS 2.0.3 by S. Christian Collins is an optional user-approved sound library. The official README explicitly provides the GitHub repository for automated packaging. The library binary is not bundled or hosted by ML Studio. The complete custom licence is retained in GENERALUSER-LICENSE.txt and installed alongside the download. The author's licence explains the inherited sample provenance; retain it unchanged. Instrument banks remain separately licensed data. Do not present GeneralUser sounds as original ML recordings or link directly to the author's website-hosted download on our website.

Source library APIs: FluidSynth include/fluidsynth/{settings,synth,sfont}.h. Engine instances are prepared off the audio callback; existing saved assets load during initialization before playback/export. Live replacement uses bounded pending/retired slots, revision checks and background destruction. Paths and parameters are saved, not SF2 bytes. MIDI events are dispatched at host-provided offsets; internal FluidSynth rendering uses its usual block buffering. One selected instrument per instance. Download uses HTTPS, explicit consent, size/hash checks, fixed managed filename, an OS file lock, atomic completion, cancellable progress and a reusable shared installation. Failed/partial files are never treated as installed. Stock-plugin visibility hides controls without altering state/audio.
