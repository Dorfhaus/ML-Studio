# ML Time Shaper, Amp and Vocal Tune

ML Time Shaper adapts B.Oops FxChopper.hpp and FxStutter.hpp by Sven Jähnichen (copyright 2020), GPL-3.0-or-later. Source: https://github.com/sjaehn/BOops revision 880cfbdbc985cf5b5131951536d0e68291444ef0. Original references and licence are in vendor/boops. ML adds host beat sync, 16 editable/automatable gains, preset/drag undo, mode/gain smoothing and bounded history. Gate and first-slice repeat are supported; this is not the entire B.Oops effect suite or an arbitrary playback-speed curve editor. Maximum cycle is four quarter-note beats at 40–300 BPM; fallback 120 BPM. No fixed latency.

ML Vocal Tune reuses crates/os-dsp/src/snaptune.rs and vendor/snaptune, including its existing AGPL-3.0 notices. No second tuning engine or x42 code is added. The same live tuning mode, key/scale/voice mapping and key-learning algorithm as the mixer are used. Added independent stock editor, host parameters, aligned dry delay and fixed reported latency. Avoid using both mixer tuning and this insert unless double processing is intentional.

ML Amp uses NeuralAmpModelerCore by Steven Atkinson (MIT), https://github.com/sdatkinson/NeuralAmpModelerCore revision d3189ed482ded880c128bf312941266c4fa5ceec. Eigen dependency bc3b39870ecb690a623a3f49149a358b95c5781d is built EIGEN_MPL2_ONLY; retained licence files describe its modules. nlohmann/json retains its embedded MIT notice. AudioDSPTools revision 0827c6c2fc0deced568536142ea86f189e0b98a1 provides the Lanczos rate-conversion container; its original iPlug/WDL/Surge notices remain in the headers. Cabinet convolution reuses ML Convolver (FFTConvolver, MIT; see ../ml-space-core/UPSTREAM.md).

Supported NAM architectures: mono LSTM, WaveNet, ConvNet and Linear, two independent instances for stereo. Nested/conditioned/slimmable variants are rejected; structural bounds and truncated-weight checks run before unsafe consumption. Linear uses direct convolution, at most 4096 taps. Model text <=8 MiB/1M weights; cabinet WAV <=500 ms. Models are user-provided: no third-party trained weights/cabinet captures are bundled. Assets embed in project state. Fixed 256-sample latency includes conversion and aligned dry. Sample rates 8–192 kHz; declared model rates 32–192 kHz. A model with unknown rate runs at host rate.

ML modifications to NAM are marked in vendor source: cached prewarmed-state restore for LSTM/ConvNet and access to WaveNet's existing cache; buffer clearing; bounded weight reads; allocation-free ConvNet head for variable blocks. Resampler changes remove iPlug constants, reset phases deterministically and correct the interpolation index and widen/lower the Lanczos filter for antialiased downsampling. New native wrapper prepares outside processing, pads to fixed latency and serializes factory access. Rust worker prepares file loads and retires old instances away from audio, with 20 ms replacement crossfades. Invalid loads retain accepted assets; non-finite/excessive model output falls back to aligned dry.

All three use the standard native stock editor/host frame, saved parameters and automation. Extra controls follow Stock plugins > Advanced DSP controls visibility without deleting settings. Windows tests do not establish Mac/Linux runtime readiness.
